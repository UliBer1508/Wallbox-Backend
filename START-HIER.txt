WALLBOX-BACKEND — Erste Schritte
================================

1. INSTALLATION
   Rechtsklick auf  setup.ps1  ->  "Mit PowerShell ausführen"
   Installiert Node.js (falls nötig), alle Module, legt .env an.

2. KONFIGURATION
   Datei  .env  öffnen und echte Werte eintragen:
   - STRIPE_SECRET_KEY, ADMIN_PASSWORD, UPLOAD_PASSWORD

3. STARTEN (zum Testen)
     npm start
   Browser:  Admin  http://localhost:8080/
             Gäste  http://localhost:8080/guest?wb=p30c

DOKUMENTATION:
   WALLBOX-ANLEITUNGEN.md    alle Aufgaben (Stripe, QR, Tunnel, NSSM,
                             Tailscale, Fehlersuche)
   WALLBOX-DOKUMENTATION.md  Architektur, Schichten, Datenbank, API

HILFS-SKRIPTE:
   install-services.bat      Autostart-Dienste einrichten (als Admin)
   remove-services.bat       Dienste wieder entfernen (als Admin)
   sync-from-onedrive.bat    Dateien aus OneDrive übernehmen (dein Workflow)

WICHTIG vor dem Live-Betrieb:
   - .env niemals in GitHub committen (.gitignore schützt davor)
   - eCarUp von der P30X trennen (siehe ANLEITUNGEN, Abschnitt 9)
   - Modbus-Schreibregister [PRUEFEN@PC] in src/keba.js verifizieren
